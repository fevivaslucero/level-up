LEVEL UP — publicación en GitHub Pages

1. Descomprimí esta carpeta.
2. Subí index.html, manifest.webmanifest, sw.js e icon.svg a la raíz de un repositorio de GitHub.
3. En GitHub: Settings > Pages.
4. En "Build and deployment", elegí "Deploy from a branch".
5. Elegí la rama main y la carpeta /(root), y guardá.
6. Esperá a que GitHub Pages publique el sitio.

Para instalar en el celular:
- Android: abrí la web publicada en Chrome y usá "Instalar aplicación" o "Agregar a pantalla principal".
- iPhone: abrí en Safari, tocá Compartir y luego "Agregar a pantalla de inicio".

Los datos de hábitos quedan guardados en el almacenamiento local de cada navegador/dispositivo.
No se sincronizan entre celular y computadora.
El service worker permite cargar recursos ya visitados sin conexión.
Los recordatorios programados de esta versión requieren que la página esté abierta; las notificaciones push fiables con la página cerrada necesitan un backend/servicio push adicional.
